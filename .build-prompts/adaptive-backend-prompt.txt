PHASE 1 - New file backend/src/lib/weeklyRampEngine.js
- Pure function decideWeeklyRamp({ weeklyMileageHistory, plannedNextWeekMiles, readinessTrend }).
- Compute ACWR = last 7 days load divided by 28-day average daily load (guard divide-by-zero).
- Decision rules:
  - ACWR greater than 1.5 OR readinessTrend is red-trend => DELOAD, targetMiles = min(plannedNextWeekMiles, 0.9 times currentWeekMiles).
  - ACWR between 1.3 and 1.5 inclusive OR readinessTrend flat/declining => HOLD, targetMiles = currentWeekMiles.
  - ACWR less than 1.3 AND readinessTrend stable/improving => ADVANCE, targetMiles = min(plannedNextWeekMiles, currentWeekMiles times 1.10).
- Hard cap: never return targetMiles greater than currentWeekMiles times 1.10 (the 10 percent rule).
- Empty/insufficient history => decision PASSTHROUGH, targetMiles = plannedNextWeekMiles unchanged (must be byte-identical to today for users with no history).
- Return an object: decision, targetMiles, acwr, reason (array of short strings), drivers (array).
- Put all tunable constants (thresholds, cap) as named consts at the top of the file.

PHASE 3 - New file backend/src/lib/strengthAdjunct.js
